📊 Sales Dashboard (Excel Project)An interactive, data-driven Excel Dashboard designed to analyze retail sales performance, uncover buying patterns, and track Key Performance Indicators (KPIs). This project transforms raw transactional data into actionable business insights using data cleaning, pivot tables, and dynamic visual tracking.  🚀 Project OverviewThe objective of this project is to provide a comprehensive view of business sales health. It enables stakeholders to quickly filter through regions, product categories, and timeframes to make strategic, data-backed decisions.Key Features:Dynamic Slicers: Filter the entire dashboard instantly by Region, Product Category, or Time Period.KPI Metrics Tracker: High-level visibility into Total Revenue, Profit Margins, Total Units Sold, and Average Order Value (AOV).Sales Trends Over Time: Visual line charts mapping out monthly or quarterly sales performance to identify seasonality.Top Performing Products & Regions: Bar/Column charts highlighting driving revenue channels.Customer Demographics: Brief breakdown of sales segmented by customer segments/types (if applicable).🛠️ Tech Stack & Tools UsedMicrosoft Excel (Advanced)Power Query / Data Cleaning: For handling missing values, data type formatting, and eliminating duplicates.Pivot Tables & Pivot Charts: For summarizing hundreds/thousands of rows of raw data.  Advanced Formulas: VLOOKUP, INDEX/MATCH, IF statements, SUMIFS.Conditional Formatting: For highlighting high/low-performing margins.📂 Repository StructurePlaintext├── Data/
